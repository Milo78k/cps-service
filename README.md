# CPS Service

Учебная вёрстка сайта сервисного центра: услуги, ремонтируемые бренды и устройства, цены и контактные формы.

## Что есть в репозитории

- HTML-страница с боковой навигацией и мобильной шапкой.
- Секции брендов, устройств и цен.
- Разметка слайдеров Swiper и модальных контактных форм.
- CSS, изображения, локальные шрифты и собранный JavaScript bundle.

## Стек

HTML, CSS, JavaScript, Swiper.

## Локальный просмотр

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`.
